# Phase 3 — genuine 180-day CORE/AI paper trade replay

This is an **offline historical scenario simulator**. It does not submit an
order to OKX, Binance, Hummingbot, CCXT or Freqtrade native trading APIs.
Its `actual_fill_price` is **the modeled price within the replay**, not an
observed exchange fill. Do not use results as a verified trading performance
claim, an independent Kotlin parity certificate or a proof of FreqAI quality.

## Data lineage / runtime
1. Codemagic manual workflow `dual-strategy-phase3-native-research` (branch
   `feature/dual-strategy-phase3-paper-replay-20261030`) downloads and exports
   OKX USDT perpetual 15m/1h/5m candles; verifies **180 closed days** and
   **35+ days training prehistory**, with SHA-256 for both major/detail sets.
2. Two guarded Freqtrade 2026.9 native backtests use the identical OKX native
   data directory. CORE uses a derived config with FreqAI off; FreqAI runs
   `ChartProFreqaiResearch` + real `LightGBMRegressor`. Both native entry
   columns remain 0 and confirm_trade_entry returns False.
3. Only the FreqAI native **backtest** writes
   `artifacts/phase3/native/freqai-native-predictions.csv` (no predictions
   generated by this paper simulator). The CSV carries `do_predict`,
   `&-future_return` model output, candle timestamp, OHLCV, model ID and pair.
   Rejected model forecasts never become signals.
4. `native-research-180.json` pins that CSV SHA-256, model identifier and
   M15/H1/5m dataset hashes. Paper replay rejects mismatched provenance,
   missing native success evidence, mixed markets or tampered forecast rows.
   Model training-cutoff attestation and OOS trading quality are **not**
   independently verified; the AI risk admission here is restricted to this
   offline research replay only.
5. Replay 3 independent paper accounts on the same 180 days: `CORE_ONLY`,
   `AI_ONLY`, `DUAL`. For DUAL, opposite CORE/AI directions block entry;
   a valid AI-only signal can enter even when CORE has none. Shared Risk
   `admit` checks every entry and `admit_adjustment` checks a single
   same-side DCA and collateral, without altering normal entry policy.
6. Entry, DCA, confirmed TP/Soft SL decisions happen on closed 15m candles
   and fill at the next 5m **open**. Emergency SL checks every 5m low/high,
   applies conservative opening-gap reference and has precedence over
   same-candle DCA and a previously confirmed exit that gaps through the stop.
   Static 5bps slippage and 0.05% per-side commissions are assumptions,
   **not** exchange-confirmed costs. Stop price against future intrabar OHLC
   remains uncertain.

## Exported evidence

Under `artifacts/phase3/paper/` for **each** CORE_ONLY / AI_ONLY / DUAL:

- `paper-*-events.csv`: `expected_fill_price` (decision reference),
  `actual_fill_price` (simulated executed price),
  `fill_difference = actual - expected`, time of decision/confirmation/fill,
  signal origin, side, margin, fee and both canonical checksums
- `paper-*-trades.csv`: closed trades, DCA count, net PnL **excluding**
  unverified funding, separate fees, gross ROE, exit cause
- `paper-*-equity.csv`: mark-to-market equity, unrealized PnL and drawdown
- `paper-*-report.json` plus `paper-180-summary.json`: per-mode totals,
  risk denials / DCA collateral rejection, sources conflicts and explicit
  unverified flags

An open position at the 180-day cutoff stays open. No invented exit or fill.
`paper_trade_bearing_verified=true` requires **at least one closed trade**
for BOTH CORE_ONLY and AI_ONLY; if the real signals do not produce such
trades, the Codemagic job exits nonzero with diagnostic artifacts. The
baseline margin 50% + DCA 100% of entry can exhaust collateral after
fees / unrealized loss, in which case DCA is **rejected**, not forced.

## What remains before 360 days / production

- Independent Kotlin event traces over the identical input SHA.
- Confirmed complete funding, margin/liquidation and mark-price history
  for the whole test window; OKX MARK history has limitations.
- Model training/label cutoff attestation, walk-forward OOS quality and
  no-lookahead proofs; raw FreqAI `do_predict` is not enough.
- Fills verified against an actual matching-order-book model or exchange
  executions (OHLCV alone only allows *simulated* execution).
- Explicit operator review of 180-day paper output before enabling the
  360-day workflow. The Codemagic `PHASE3_DAYS=360` setting intentionally
  **fails closed** until that evidence is available.

The default CORE RSI/ADX/Smart DCA/TP/Soft SL/Emergency SL parameters are
unchanged. Do not merge this draft branch into `main` or release an APK
based on replay results without independent review.
