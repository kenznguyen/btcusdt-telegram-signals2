### 2.1 Construction and connection ownership

- Constructor accepts only a T0 DB path and stores the path/configuration without filesystem or SQLite access.
- No LeaseStore object is injected into the Gateway. The Gateway reads feeder_leases through the same SQLite connection and BEGIN IMMEDIATE transaction used for candle writes.
- Candle and lease tables must be in the same physical SQLite database.
- SQLite is the only G1 backend. No backend selector or PostgreSQL fallback exists.
- GatewayWriteError is the common base; the three typed subclasses remain distinguishable.
- now_ms is a zero-argument callable returning a nonnegative UTC epoch-millisecond integer. It is not a scalar timestamp.

### 2.2 Existing G0 harness changes required

The current market_data/test_gateway_runtime.py on the G0 harness branch does not yet match the reconciled G1 API. The RED test change set must:

1. Change Gateway construction from T0WriteGateway(db_path=..., lease_store=...) to T0WriteGateway(db_path=...).
2. Change every scalar now_ms=self.now argument to a deterministic callable.
3. Convert the acquired lease record into LeaseFence(lease_name, owner_id, generation); do not pass the old Lease record directly.
4. Keep GatewayWriteError as the common catch type, but assert LeaseRejected, CandleBatchRejected, or GatewayStorageError for the relevant behavior.
5. Remove the G1 test's dependency on PaperWriterGate. A fabricated/wrong-scope object can be rejected by G1 input validation; actual Paper-token/T0-token non-interchangeability belongs in the separate P1 integration suite.
6. Remove the old constructor test using backend="postgres". Assert that the SQLite-only constructor has no backend selector and that no PostgreSQL canonical adapter is exposed/enabled.
7. Do not use skipIf(Gateway is None) for behavioral tests. During RED, missing API must produce explicit CONTRACT RED failures, not silently skipped tests. Catch only the expected missing market_data.gateway module; unrelated import/dependency errors must remain visible as invalid harness failures.

## 3. Isolated fixture contract

Every test owns a fresh tempfile.TemporaryDirectory and a unique SQLite path. No shared fixture DB and no environment-derived canonical path.

The fixture explicitly creates the two source-observed tables in the temporary DB:

- candles: exact columns and primary key from market_data/store.py.
- feeder_leases: exact columns/check constraints from LeaseStore._transaction().

Fixture DDL is test setup only. It must not call CandleStore.__init__() or rely on Gateway construction to initialize schema. Seed synthetic lease rows with a known lease name, owner, generation and expiry. Candle fixtures use the existing validated Candle model and aligned 15m timestamps.

All state assertions query the DB after the operation through an independent SQLite connection. Negative tests must assert both the expected typed error and the persisted state.

Environment isolation:
- MARKET_DATA_DB, T0_FEEDER_LEASE_DB, PAPER_DB, PAPER_TRADING_DB unset/empty.
- Binance and OKX credentials unset.
- ai_execution_enabled=false.
- No network, exchange adapter, Android/PC DB, canonical path, or external service.

## 4. G1 test matrix

| ID | Test | Arrange / action | Required assertion |
|---|---|---|---|
| G1-01 | Valid lease | Matching lease name, owner and generation; submit two valid candles | Return accepted count 2; both rows persist atomically |
| G1-02 | Expired lease | Expiry equal to or earlier than initial now_ms() | LeaseRejected; zero candle rows persist |
| G1-03 | Wrong owner | Valid lease row but different LeaseFence.owner_id | LeaseRejected; zero rows persist |
| G1-04 | Stale generation | Same lease/owner but lower generation | LeaseRejected; zero rows persist |
| G1-05 | Takeover wins first | Commit new owner/generation before old writer calls Gateway | Old fence rejected; no old-writer candle persists; new lease row remains authoritative |
| G1-06 | Writer transaction wins first | Writer acquires BEGIN IMMEDIATE; independent takeover connection attempts write while writer holds lock | Takeover cannot commit while old transaction owns write lock; old admitted batch commits; takeover then commits; final lease and candle rows prove this order |
| G1-07 | Invalid candle in batch | Mix valid Candle and invalid non-Candle/malformed item | CandleBatchRejected; no partial rows |
| G1-08 | Injected mid-batch SQL failure | Temporary-DB trigger raises after an earlier insert in the same batch | GatewayStorageError or documented storage/constraint subtype; entire batch rolled back |
| G1-09 | Duplicate/conflict semantics | Replay identical candle; then submit same identity with changed OHLCV | Identical replay returns 0 and creates no duplicate; changed OHLCV rejects without overwrite; original available_at_ms remains unchanged |
| G1-10 | Missing/unavailable Gateway | Empty/invalid path or inaccessible temporary path | Explicit configuration/storage failure; no DB/parent creation and no direct-store fallback |
| G1-11 | Constructor/read side effects | Construct against missing nested path; call read against missing path and existing temp DB | Constructor creates nothing; missing read fails without file creation; existing read performs no DDL/DML/schema/data mutation |
| G1-12 | PostgreSQL disabled | Attempt to select or invoke a PostgreSQL canonical backend | Rejected before storage access; no PostgreSQL canonical write path |
| G1-13 | Empty batch | Empty sequence, lease_token=None, clock callable that would fail if invoked, missing DB path | Return 0; no DB/file/parent, transaction, lease lookup, clock invocation, DDL or DML |
| G1-14a | Expiry before final admission | Initial clock valid; final clock returns expired time | LeaseRejected; entire batch rolled back |
| G1-14b | Expiry after final admission | Deterministic clock returns valid time at final check and advances its external state to expired immediately after returning | Already-admitted batch commits; expiry after linearization does not retroactively revoke it |

### 4.1 Deterministic concurrency method

Use independent SQLite connections to the same temporary DB; separate processes are preferred where the test runner permits reliable coordination.

For G1-05, commit takeover first and then invoke the old writer.

For G1-06, use an injected deterministic clock callable as a barrier: its first invocation occurs only after the Gateway has acquired BEGIN IMMEDIATE. Signal the test coordinator and hold the writer at that point. A second independent connection attempts BEGIN IMMEDIATE with zero timeout and must observe SQLite's lock/busy result while the writer owns the transaction. Release the writer, verify its final check and commit, then retry/commit takeover. Assert durable candle rows and final authoritative lease generation. Do not use timing sleeps or a shared SQLite connection.

### 4.2 Atomic rollback method

- G1-07 validates malformed batch rejection and confirms no mutation.
- G1-08 uses a real SQLite trigger on the temporary DB to raise on a later row, after an earlier row has been inserted in the same transaction. Query afterward from a fresh connection and assert zero rows from the failed batch.
- G1-14a checks expiry at the final admission point and confirms rollback through persisted state.
- An exception assertion alone is insufficient; persisted state is mandatory.

### 4.3 Read-only and empty-batch checks

- Constructor test uses a non-existent nested path and asserts neither parent directory nor DB/WAL file is created.
- Missing-file read test asserts the read fails closed without creating a file.
- Existing-file read test snapshots schema and row state before/after. No DDL/DML, schema initialization, status mutation or data mutation is allowed.
- Empty-batch test must use a clock callable that raises if called and a DB path that does not exist. A successful return of 0 plus unchanged filesystem state proves the no-op contract.

## 6. RED / GREEN acceptance

- Add/update the 14 behavioral cases before implementing market_data/gateway.py.

- A skipped behavioral test is not a RED assertion and never counts as PASS.

- Implement the smallest Gateway primitive satisfying the frozen contract.
- Run focused G1 tests; all 14 cases must execute with zero skips.
