# P5.2.5 Complete Writer / Mutator Inventory (baseline audit)

Baseline: a58b6163a78861ecf5bb7d2c8fc11aa420142837
Scope: T0 canonical market data and PaperLedger runtime. This is a source-level inventory of checked paths, not proof against dynamically imported or external writers.

## T0 canonical market data

| Path | Write-capable surface | Current behavior / required control |
|---|---|---|
| market_data/store.py | CandleStore.__init__, insert, insert_fenced | Constructor creates parent directory, WAL and schema; insert is unfenced; insert_fenced checks Lease in same SQLite transaction. Constructor/schema init must be separated or Gateway-authorized. |
| market_data/storage.py | SQLiteCandleStore.insert, insert_fenced; PostgresStore.insert; create_store | Facade exposes unfenced write APIs. SQLite lazily constructs CandleStore. Postgres forwards directly to PostgresCandleStore. |

## Paper execution

### Direct mutating public methods on PaperLedger

- `__init__`: creates parent directory; opens DB; WAL; creates/migrates `paper_state`, `paper_orders`, `paper_books`, `paper_audit`, `paper_strategy_state`; calls `risk_control.ensure` and `equity_history.ensure`; inserts initial/legacy rows.
- `submit`: BEGIN IMMEDIATE; updates paper_state, paper_books, paper_strategy_state; inserts paper_orders and paper_audit; may set Kill Switch through risk_control.
- `record_equity`: BEGIN IMMEDIATE; calls equity_history.record, which may create tables/indexes and mutate paper_equity_history, paper_daily_baselines, paper_account_config.
- `set_paused`: BEGIN IMMEDIATE; updates paper_state, risk_control and paper_audit.
- `set_killed`: BEGIN IMMEDIATE; updates risk_control and paper_audit.
- `reset_kill`: BEGIN IMMEDIATE; updates risk_control and paper_audit.
- `cancel`: BEGIN IMMEDIATE; updates paper_orders and paper_audit.

### Helper mutators (must only execute inside an admitted Ledger transaction)

- `PaperLedger.audit(connection,...)`: inserts paper_audit.
- `risk_control.ensure(connection)`: CREATE TABLE and INSERT OR IGNORE.
- `risk_control.set_kill`, `reset_kill`, `set_paused`: UPDATE paper_risk_control.
- `equity_history.ensure(connection)`: CREATE TABLE / INDEX.
- `equity_history.record(connection,...)`: calls ensure; inserts/updates paper_account_config and paper_daily_baselines; inserts paper_equity_history.
- `equity_history.snapshot(connection,...)`: currently calls ensure and is therefore NOT truly read-only; this is a read API with schema mutation and must be split into read-only snapshot vs explicit schema initialization.
- `equity_history.block_reason(connection,...)`: must be audited for any write side effects; called during submit transaction.
- `read_snapshot`, `read_audit`, `snapshot`, `strategy_state`, `audit_snapshot`: intended read paths; must not create DB/schema or write.

## Test entry points / CI

- Python standard library `unittest`.
- Local documented commands in README: market_data.test_store/test_sync/test_api; integrations discovery; ci discovery.
- Codemagic `canonical-market-data`: market data tests, integrations discovery, CI policy discovery, paper system tests (`paper_execution.test_ledger`, `test_risk_control`, `test_equity`), CLI help and compileall.
- requirements-ci.txt currently installs PyYAML; test framework is stdlib unittest.
- Existing RED PR #111/#112 checks are static source-contract tests. They do not prove transaction races, token fencing, drain behavior or rollback atomicity.

## Inventory exclusions / open proof obligations

1. Search all `.py` files and scripts for SQLite write SQL, `BEGIN IMMEDIATE`, `INSERT/UPDATE/DELETE/CREATE/DROP/ALTER`, store constructors and `.insert(` calls. This API connector cannot execute a full repository checkout/test run, so a dynamic AST/grep sweep on Codemagic remains required.
2. Inspect every imported module that writes to the same canonical DB path; especially CLI entry points, recovery hooks, migration scripts, test helpers and deployment commands.
3. Verify no process other than Gateway can open canonical SQLite read-write. SQLite itself has no per-table ACL; filesystem/process isolation is required.
4. Confirm all paper mutators are gated at transaction commit, including schema creation and helper calls, not merely public method entry.
5. Test snapshots during drain; `equity_history.snapshot` must not perform DDL or inserts.
6. Verify Postgres canonical writer is disabled by default; Kraken Spot remains physically separate.

## Verdict

Inventory identifies the principal direct writer and helper mutator surfaces. It is sufficient to author focused runtime contracts, but it is not yet a verified exhaustive runtime proof. Codemagic must run a repository-wide writer scan and the new runtime suite before implementation can be considered ready.
