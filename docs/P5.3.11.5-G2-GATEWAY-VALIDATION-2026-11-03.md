## Implemented contract

1. `sync_window()` requires the concrete `T0WriteGateway`, typed `LeaseFence`, and a separate lease clock.
2. Every non-empty OHLCV page is committed through `gateway.insert_batch()`; legacy `store.insert()` and `store.insert_fenced()` paths are not used by canonical sync.
3. Feeder Scheduler and Recovery use the same Gateway-backed sync callback.
4. Observation time and lease-admission time are separate inputs.
5. The canonical sync CLI is SQLite-only and requires explicit lease owner and generation.
6. `CandleStore` and `LeaseStore` constructors are inert. Schema creation is available only through explicit `initialize_schema()` calls; runtime lease transactions contain no DDL.
7. Pagination failure preserves already committed earlier pages; duplicate, conflict, empty-batch, stale-generation, and final-admission expiry behavior are covered by the G2 tests.
