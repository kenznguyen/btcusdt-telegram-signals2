## Approval and scope

User approval: `APPROVE P1.8.5`.

This increment implements an isolated, deterministic Python reference model that admits both `CORE` and `AI` intents through one `SharedRiskAdmission.admit()` boundary. `admit_batch()` merges the two strategy feeds and delegates each intent to that same method.

The shared gate checks:
- Kill Switch before reservation.
- Daily loss threshold.
- Maximum open-position count.
- Maximum total exposure, including reservations already admitted in the same process.
- Exact-decimal positive notional, allowed strategy source (`CORE` / `AI`) and side (`LONG` / `SHORT`).
- Intent-ID idempotency: identical bytes return the original decision/reservation; changed bytes under the same ID are rejected.
- Rejected intents never create reservations.

This is a **synthetic reference model**, not a production Shared Risk Engine. It has no connection to Strategy Core, AI signal generation, T1 runtime, T0, database, exchange, provider, VPS, network, or execution adapter.
