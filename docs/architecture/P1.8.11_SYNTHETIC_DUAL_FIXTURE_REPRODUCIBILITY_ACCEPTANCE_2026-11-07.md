## Workflow changes

The workflow now:
1. Generates fixture A and fixture B in separate CLI invocations using the same fixed seed, namespace, UTC base time, event count and exact triggering source SHA.
2. Compares the complete output directories recursively with `diff -qr`.
3. Independently runs `sha256sum -c fixture.sha256` inside each fixture directory.
4. Compares the two inventory files byte-for-byte with `cmp`.
5. Records source SHA, both inventory-file SHA-256 values, file counts and explicit byte-comparison status.
6. Uploads both `synthetic-evidence-output-a/**` and `synthetic-evidence-output-b/**`; artifact upload now fails if requested evidence files are missing.
7. Adds a unit contract that independently generates and writes two fixtures, checks equal complete file inventories and compares every output file byte-for-byte.
