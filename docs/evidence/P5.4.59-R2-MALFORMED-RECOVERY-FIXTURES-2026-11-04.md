## Fixture expansion

Extended `market_data/test_feeder_recovery.py` with three test methods:

1. Missing `coverage.complete` field fails closed.
2. Explicit `coverage.complete = None` fails closed.
3. Non-boolean values `0`, `1`, `"false"`, and `"true"` fail closed.

All cases assert the established `ValueError` contract: `coverage completeness contradicts reported gaps`.

The production `RecoveryPlanner` implementation did not need modification: its existing strict `type(complete) is bool` validation already rejects missing, null and non-boolean values. This increment adds durable regression coverage rather than changing runtime behavior.
