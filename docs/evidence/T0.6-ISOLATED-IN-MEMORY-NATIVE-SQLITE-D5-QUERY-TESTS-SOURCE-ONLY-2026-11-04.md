## Implementation
- Added host-native CMake/CTest harness including the production native D5 implementation; opens only SQLite `:memory:`.
- Uses the pinned SQLite 3.54.1 amalgamation and exact expected source ID.
- Added a compile-time payload-ceiling seam. Production default remains 32 MiB; the isolated harness lowers it to 64 KiB for deterministic oversize testing.
- Four native scenarios: populated schema success (strict tables, generated stored column, unique constraint, partial descending index, view, foreign key); FTS5 virtual-table rejection; SQLite authorizer SELECT denial -> `D5_QUERY_FAILED`; payload-ceiling rejection -> `D5_PAYLOAD_TOO_LARGE`.
- Successful native query emitted a 1,526-byte D5WT fixture. Both regular and `.paper` JVM variants decode the exact fixture with `NativeSqliteD5WireDecoder`, assert schema details, and invoke `CanonicalD5Serializer.serialize()` / `sha256Hex()`.
- No production query SQL, wire version, canonical serializer format or production payload limit changed.
