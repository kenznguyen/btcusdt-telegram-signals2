1. Deterministic fixture inventory across Candles, Paper Ledger, Risk State, Paper State and feeder lease/status tables.
2. SQLite Online Backup API round trip with schema and logical row equality.
3. WAL snapshot boundary: an uncommitted writer transaction is absent from the snapshot; a subsequent committed snapshot includes it.
4. Read-only verifier cannot mutate source state.
5. Missing required table fails closed.
6. Missing required singleton risk state fails closed.
7. Logical row tampering is detected.
8. Corrupt SQLite image is rejected.
9. Atomic staging/verification/publication; existing destination is not overwritten.
10. Path escape outside the fixture root is rejected.
11. Symlink destination is rejected without modifying its target.
12. Split-store manifest requires one shared barrier ID, both store snapshots and a positive restore epoch; the validator explicitly does **not** claim cross-store atomicity.
