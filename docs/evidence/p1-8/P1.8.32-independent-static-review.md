## 3. Correction made during review

- D0: application/process termination.
- D1: database process restart.
- D2: host restart.
- D3: storage/provider interruption.
- D4: power loss/device failure/filesystem corruption.

The corrected table restricts claims to the exact tested fault model and does not infer broader hardware/provider resilience. The reviewed blob SHA above refers to the corrected revision.
