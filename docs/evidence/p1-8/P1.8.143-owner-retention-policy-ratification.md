## 2. Ratified decisions

### RET-01 — T0 canonical data

**Approved option B: protected by default, exceptional review only.**

- T0 canonical data remains protected from routine lifecycle deletion.
- No automatic or scheduled deletion path for T0 is permitted.
- A narrowly scoped exception may only be considered for a separately evidenced, binding legal or security requirement, with competent review and a new explicit owner decision.
- This ratification does not approve any exception, object disposition, deletion request or execution.

### RET-02 — Future deletion-eligibility review classes

**Approved option B: limited noncanonical classes only.**

Only the following may enter a future, read-only, exact-object/version eligibility assessment:

1. T4 deterministic caches, read models and materializations, after deterministic rebuildability, source availability and dependency closure are proven.
2. T2 ephemeral inference outputs, after proving they do not underpin material decisions, claims or required evidence.
3. T1 raw observations, only after exact dependent outputs are demonstrably reproducible from retained authoritative inputs and all applicable obligations are closed.
4. Individually identified noncanonical copies, after copy-specific dependency, hold, recovery-chain and lineage checks.

This is permission to consider an object for assessment only. It does not make any class or object deletion-eligible by default and does not authorize mutation.

The following remain excluded from ordinary class-wide deletion review: T0 canonical data; CORE_LEDGER; AI_LEDGER; T3 event, reconciliation and audit records while needed for paper-outcome reconstruction; governance approvals, policy history, tombstones and lifecycle evidence; unknown, unclassified, orphaned or incompletely inventoried data.
