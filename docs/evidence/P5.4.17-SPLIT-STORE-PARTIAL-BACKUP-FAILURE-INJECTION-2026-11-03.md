2. `test_split_store_backup_set_publishes_both_stores_and_manifest_together` verifies the success path publishes both SQLite snapshots and the manifest as one completed fixture directory.

The helper is located in `ci/backup_restore_test_support.py`. It is explicitly test support, not a production multi-store coordinator. Its directory rename result is limited to the GitHub Actions Linux fixture filesystem and does not establish a cross-database consistent snapshot barrier or Windows behavior.
