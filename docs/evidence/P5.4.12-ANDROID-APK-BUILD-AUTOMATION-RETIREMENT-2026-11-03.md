## 1. Scope

The owner requested disabling unnecessary automatic APK build workflows. This increment audits both GitHub Actions and the legacy Codemagic configuration, removes obsolete APK build definitions, adds regression protection, and verifies the repository's integrated CI gate.

No Android runtime, application source, signing material, or build outputs were changed. No APK was built or signed.

## 2. Retired workflows

The following Codemagic workflows were removed from `codemagic.yaml`:
- `android-chart-pro-debug`: automatic push-triggered Debug and Parallel APK build, including Android unit tests, APK identity verification and APK artifact publication.
- `android-chart-pro-release`: manually invoked signed Release APK build and signature artifact publication.

The Codemagic configuration retains its top-level `workflows:` mapping and non-Android legacy entries. Codemagic remains retired as a CI runner under the owner policy; no Codemagic run was started.

No GitHub Actions workflow was found that builds or publishes Android APKs. All nine current `.github/workflows/*.yml` files were scanned for:
- Gradle assemble tasks (`assembleDebug`, `assembleRelease`, `assembleParallel`);
- Android setup/release scripts;
- APK output paths and APK artifact names.

No matches were found.

## 3. Regression protection

Updated `ci/test_ci_policy.py`:
- Replaced prior assertions that required the obsolete Android Debug APK workflow.
- Added assertions that the two Codemagic Android workflow definitions and their Gradle/release commands remain absent.
- Added a GitHub Actions scan that rejects Android APK build/publish commands and artifact paths in any current workflow YAML.

This prevents accidental reintroduction of automatic APK packaging through either CI configuration.
